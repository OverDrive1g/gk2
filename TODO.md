# редактор дерева крафтов для подземной мастерской

интерфейс представляет из себя 2 колонки. 1 колонка рецепты крафтов и список материалов, 2 поле для самого дерева
1 колонка занимает 20% 2 все остальное, т.е. 80%

В первой колонке списком представлены рецепты. слево иконка изголавлевоемого рецепта. сверху название изголавлевоемого рецепта. снизу иконки с названием требуемых материалов(до 2х штук)
Рецепты можно добавлять посредством кнопки которая расположена сверху в списке рецептов

Окно добавления рецепты должно быть модальным. изголавлеваемый материал должен выбираться из списка. аналогично для требуемых материалов. иконки должны добавляться как файлом так и из буфера обмена

Снизу в 1 колонке должен быть список всех материалов. Так же с возможностью добавления как и для рецептов. иконки должны добавляться как файлом так и из буфера обмена

В второй колонке графический редактор на нодах. в которые драг-н-дропов можно добавть рецепт. Нода должна представлять из себя прямоугольник с входяищими и выходящими коннекторами. Конекторами можно соеденять блоки. На коннекторах должен быть изображон итем который туда должен входить или выходить. Т.е. коннекторы должны быть 2х типов, входящие и выходящие. 


Все данные должны сохраняться в JSON. Должна быть возможность выгружать данные и загружать. 

По итогу должна получиться html страничка с стилями и js. Выбор фреймворка и библиотек оставляю на тебе. на компе стоит nodejs 24 версии. Моежшь заиспользовать его
