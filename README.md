# Подземная мастерская

Редактор дерева крафтов без зависимостей. Откройте `index.html` в современном браузере либо запустите на Node.js 24:

```sh
npm start
```

Адрес: http://127.0.0.1:3000. Устанавливать пакеты не нужно. Для проверки логики: `npm test`.

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd start` и `npm.cmd test` или запускайте сервер напрямую командой `node server.js`.

## Управление

- **Shift + клик** по ноде добавляет её в выделение или исключает из него. Перетаскивание за заголовок любой выбранной ноды перемещает всю группу с сохранением взаимного расположения и связей. Обычный клик по невыбранной ноде выбирает только её. Клик по фону или Esc снимает выделение. Delete удаляет выбранную группу и связанные линии. Новые позиции сохраняются автоматически.

- Кнопка **⇅** в заголовке ноды с двумя входами меняет входящие коннекторы местами. Изменяется только расположение на выбранной ноде: материалы, количества и связи сохраняются. Повторное нажатие возвращает исходный порядок. Порядок сохраняется в JSON в поле ноды `inputsReversed`.

- В блоке «Дополнительные ноды» доступны **Продьюсер** и **Терминатор**: нажмите кнопку или перетащите её на поле. У продьюсера выбирается материал через поиск; у него только один выход. У терминатора один универсальный вход без выходов: он принимает любой материал от рецепта, продьюсера или сплиттера. Как и остальные входы, он принимает одну связь одновременно. Оба типа сохраняются в JSON и удаляются клавишей Delete. При удалении материала удаляются его продьюсеры и связанные линии; терминаторы остаются.

- В списках выбора материалов (результат, оба входа рецепта и материал сплиттера) можно искать по любой части названия без учёта регистра. Выбор — мышью или стрелками и Enter. Esc закрывает список; ввод без выбора не меняет прежний материал. Для второго входа доступен пункт «Не требуется».
- Горячие клавиши: **A, затем M** — добавить материал; **A, затем R** — добавить рецепт. Интервал между нажатиями — до 1,5 секунды; можно также удерживать A при нажатии M/R. Работают физические клавиши независимо от раскладки. В полях ввода и открытых модальных окнах сочетания отключены.

- Под списком рецептов доступны сплиттеры **1 → 2** и **1 → 3**. Нажмите кнопку или перетащите её на поле, затем выберите материал. У сплиттера один вход и два или три пронумерованных выхода с тем же материалом. Каждый выход соединяется независимо. Сплиттеры можно перемещать и удалять как обычные ноды; они сохраняются в JSON. Удаление материала удаляет и его сплиттеры.

- Кнопки «+» добавляют материалы и рецепты. У рецепта один результат и один или два входящих материала.
- Для результата и каждого входящего материала задаётся количество за один крафт: целое число от 1. Количества отображаются в каталоге и на коннекторах нод. При изменении рецепта обновляются все его ноды. В старых сохранениях без количеств используется 1. Количества описывают рецепт; автоматического расчёта потоков и распределения по сплиттерам нет.
- Нажмите материал или «⋯» у рецепта для редактирования. Иконки загружаются файлом, кнопкой «Вставить» или через Ctrl+V в модальном окне. Изображения уменьшаются до 128 px и хранятся внутри JSON. Иконка рецепта принадлежит материалу результата.
- Перетащите рецепт на поле; альтернативно выберите карточку клавишей Tab и нажмите Enter.
- Соединение: нажмите выход справа, затем вход слева (можно в обратном порядке). Материал должен совпадать. Один вход принимает одну связь; выход может соединяться с несколькими нодами. Циклы запрещены.
- Перетаскивайте заголовок ноды для перемещения. Тяните фон для перемещения поля. Колесо или кнопки ± меняют масштаб; ⛶ помещает дерево в видимую область.
- Выделите ноду или линию и нажмите Delete. Esc отменяет создание связи. «Очистить» удаляет дерево, сохраняя каталог.
- Изменение рецепта обновляет все его ноды и удаляет несовместимые связи.
- В окне редактирования есть кнопка «Удалить рецепт» или «Удалить материал». Удаление рецепта удаляет все его ноды и их связи. Удаление материала также удаляет рецепты, где он используется как вход или результат, и их ноды. Перед удалением показывается подтверждение со списком затронутых рецептов и количеством нод и связей. Остальные материалы и ноды сохраняются.

## Сохранение

Изменения автоматически сохраняются в localStorage текущего браузера. Первый запуск показывает редактируемый пример. Экспорт JSON содержит весь каталог, встроенные иконки, позиции нод и связи. Импорт проверяет данные до замены текущей мастерской. Текущий масштаб и положение камеры не входят в файл: при открытии дерево вписывается в поле.

Для резервной копии используйте экспорт. Хранилище зависит от браузера и адреса страницы; при открытии через file:// его поведение зависит от браузера. Кнопка чтения буфера может потребовать разрешение браузера; если она недоступна, используйте Ctrl+V или файл.

На настольных экранах колонки занимают 20% и 80%. На узких экранах до 650 px каталог расширяется до 32% для удобства.

В левой колонке область над строкой статуса разделена по высоте: 60% — рецепты, 40% — материалы. Списки прокручиваются независимо; заголовки, поиск, кнопки добавления и сплиттеры остаются на месте.

Формат JSON: `version: 1`, массивы `materials` (`id`, `name`, `icon`), `recipes` (`id`, `output`, `inputs`), `nodes` (`id`, `recipe`, `x`, `y`), `edges` (`id`, `from`, `to`, `input`). Все ссылки используют ID, индекс входа начинается с нуля.

Нода сплиттера: `id`, `type: "splitter"`, `material` (ID материала), `outputs` (2 или 3), `x`, `y`. Поле `output` у связи задаёт индекс выхода с нуля; у старых файлов без этого поля используется выход 0.

Количество в рецепте: `outputQuantity` — количество результата, `inputQuantities` — массив количеств в том же порядке, что и `inputs`. При импорте старых файлов отсутствующие поля заполняются единицами.

Продьюсер в JSON: `id`, `type: "producer"`, `material`, `x`, `y`. Терминатор: `id`, `type: "terminator"`, `x`, `y`. Индекс единственного коннектора — 0.
